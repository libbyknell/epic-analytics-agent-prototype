# Personas

Generated by `kit-init.sh`. **Rule: a persona gets exactly one avatar file, reused by its exact
relative path (`../_kit/avatars/<file>`) in every beat it appears in.** Never invent a new avatar
and never let the same name render with two different images — that was dry run #2's A1/S1
friction (continuity broke because nothing recorded which photo a name used).

Shared pool: `_kit/avatars/` (copied once from the kit; every beat folder reaches it via `../_kit/avatars/`).

**Initials-only carve-out:** rendering a persona as a plain initials circle (no photo) is
a correct, real choice — not a shortcut — in two cases: (1) no photo exists for them in
`_kit/avatars/` and this is the first beat that needs one — record the color/initials you
pick in the row above so a later beat building the same name doesn't guess a different
color (dry run #2's A1/S1 continuity break, repeated in dry run #3's L1/C1); (2) the real
product itself renders the signed-in user as initials-only with no photo at all (e.g.
Tableau Cloud/Server — see the `tableau-shell`/`d360-shell` "J" rows above). In case (2),
a story persona standing in as that seat also gets initials-only — pasting a photo there
would be a fidelity regression against the real product, not an improvement.
